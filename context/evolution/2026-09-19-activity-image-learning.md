# Learning: Activity Images and Repairs

## Outcome

An optional image URL can be added to an activity without changing the rule,
session, or accounting contracts. Existing entries remain usable while the
issue registry highlights activities that still need presentation metadata.

## Reusable Insight

For optional visual metadata, validate and persist it in the same server-owned
draft boundary as the rest of the activity contract. Use a non-blocking repair
for adoption guidance, and clear it from the entry update listener once the
metadata is present. A frontend modal that renders the URL as an image keeps
the Home Assistant context and preserves animated GIF behavior.
