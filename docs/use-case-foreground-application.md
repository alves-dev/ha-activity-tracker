# [pt-BR] Caso de uso: uso de aplicativos no celular

Use um monitor de **Aplicativo em primeiro plano** quando uma integração do
celular ou computador expõe o aplicativo atualmente visível.

1. Crie um monitor e escolha **Aplicativo em primeiro plano**.
2. Selecione a entidade que informa o aplicativo.
3. Escolha se o identificador vem do estado da entidade ou de um atributo; se
   necessário, indique um atributo opcional com o nome legível do aplicativo.
4. Selecione os períodos e sensores de duração ou sessão que deseja acompanhar.

Cada troca de aplicativo encerra a sessão anterior e inicia outra. Além dos
sensores escolhidos, esse tipo de monitor cria automaticamente **Current
foreground application**, com o aplicativo da sessão atual.

# [en] Use case: mobile app usage

Use a **Foreground application** monitor when a phone or computer integration
exposes the app currently visible to the user.

1. Create a monitor and choose **Foreground application**.
2. Select the entity that reports the application.
3. Choose whether the identifier comes from the entity state or an attribute;
   if needed, enter an optional attribute with the application's friendly name.
4. Select the periods and duration or session sensors you want to track.

Each application change ends the previous session and starts another one. In
addition to the selected sensors, this monitor type automatically creates
**Current foreground application**, which reports the app in the current
session.
